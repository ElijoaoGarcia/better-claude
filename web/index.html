better-claude

Free, open-source plugins and mods for Claude Code, by @midudev.

Paste it into Claude Code. It installs the ones you picked.

    Commit
    • source
    • docs
    
        
    
          
    Type /commit, pick commit + push, commit only or a new branch, and Haiku 5.5 splits your changes into Conventional Commits, one per logical group, on the branch you are on. No secrets staged, no Claude attribution.

    Narrator
    • source
    • docs
    
        
    
          
    Click ⏸︎ narrator off at the bottom right, or type /narrator, and after each turn Claude tells you out loud what it did, in the language you wrote in, with the best free voice your system has: Siri's on macOS, Narrator's on Windows, speech-dispatcher's on Linux.

    Use Haiku
    • source
    • docs
    
        
    
          
    Start a prompt with _ and that turn runs on Haiku, its subagents too. You see it as you type, on the spinner and under the answer. Every other prompt keeps the session's model.
